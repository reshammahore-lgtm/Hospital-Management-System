# Hospital Management System

A simple patient appointment management web application built using PHP, MySQL, HTML and CSS.

## Features
- Patient appointment booking
- Doctor and appointment details
- MySQL database storage
- Appointment listing

## Technologies
- PHP
- MySQL
- HTML
- CSS

## How to Run
1. Install XAMPP.
2. Start Apache and MySQL.
3. Open phpMyAdmin.
4. Import `database.sql`.
5. Copy this folder into the XAMPP `htdocs` folder.
6. Open `http://localhost/Hospital_Management_System/`.

## Project Purpose
The system demonstrates a basic digital appointment workflow for a hospital/clinic, reducing manual appointment handling.
